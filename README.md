# 👨‍💻 قالب تلميع حساب GitHub (Profile README)

> **كيف تطبقه؟**
> 1. ادخل على حسابك في GitHub.
> 2. اضغط على **New repository** (إنشاء مستودع جديد).
> 3. اجعل اسم المستودع **مطابق تماماً لاسم المستخدم الخاص بك** (مثلاً إذا كان اسم حسابك `ali-dev`، يكون اسم المستودع `ali-dev`).
> 4. اختر المستودع **Public** وضع علامة صح على **Add a README file**.
> 5. افتح ملف `README.md` والصق بداخله الكود الموجود في الأسفل، ثم احفظ (Commit).
